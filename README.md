# 🏋️ Gym Management System

> **Manage Members. Track Progress. Simplify Operations.**

------------------------------------------------------------------------

## 🚀 Overview

A modern Gym Management System built with **Python** and **Flask** to
simplify day-to-day gym operations through secure authentication,
role-based dashboards, member management, trainer management, attendance
tracking, and responsive design.

### ✨ Highlights

-   🔐 Secure Authentication
-   👥 Role-Based Access
-   💪 Member & Trainer Management
-   📅 Attendance Tracking
-   📊 Dashboard Analytics
-   📱 Responsive Interface

------------------------------------------------------------------------

python app.py

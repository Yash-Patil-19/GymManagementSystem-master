# 🚀 Overview

Managing a gym shouldn't require endless paperwork, scattered spreadsheets, or complicated workflows.

This project transforms traditional gym management into a **modern digital platform** where administrators, trainers, receptionists, and members can work together through one secure dashboard.

Whether it's registering members, tracking fitness progress, assigning workout plans, or managing staff, everything happens in one place.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Yash-Patil-19/gym-management-system.git
```

Move inside the project

```bash
cd gym-management-system
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```
